# ساخت فایل APK انبار یار (بدون نصب هیچ ابزاری)
1. در github.com یک حساب رایگان بسازید و یک Repository جدید (شاخه main) بسازید.
2. همه فایل‌های این پوشه (از جمله پوشه .github) را در آن آپلود کنید.
3. تب Actions › «Build APK» › Run workflow.
4. پس از ۵ تا ۱۰ دقیقه، از پایین صفحه اجرا فایل «anbar-yar-apk» را دانلود کنید؛ داخل آن app-debug.apk است.
5. APK را روی گوشی کپی و نصب کنید (اجازه «نصب از منبع ناشناس» لازم است).
اطلاعات در حافظه داخلی برنامه روی گوشی می‌ماند و با پاک نشدن داده‌های برنامه حذف نمی‌شود. برای دیدن همان اطلاعات روی چند دستگاه، در تنظیمات برنامه «پایگاه داده و همگام‌سازی» را وصل کنید.
